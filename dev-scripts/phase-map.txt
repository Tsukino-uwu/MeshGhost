# Which paths belong to which phase log — the ONE definition, read by two enforcers.
#
# `dev-scripts/preflight.ps1` reads it to FIND a phase log that has fallen behind (late, in a
# batch). `.githooks/pre-commit` reads it to STOP one falling behind (early, at the commit that
# would do it). The map lived inline in preflight.ps1 until 2026-09-18; it moved here the moment a
# second reader existed, because a gate whose rule is written twice drifts, and this repo has
# already been bitten by a gate disagreeing with the rule it enforces.
#
# Format: <phase file> <pathspec> [<pathspec> ...]   — git pathspecs, whitespace-separated.
# Blank lines and # comments ignored. `lag-max <n>` sets the shared threshold.
#
# THE THRESHOLD is the user's call, 2026-09-02, and lives here so both enforcers use one number:
# three or more commits to an area with no log line is a session's worth of work unrecorded.
# The hook refuses the commit that WOULD reach it, so preflight's copy should now never fire from
# accumulation — if it does, something committed without the hook (a clone that never ran
# `git config core.hooksPath .githooks`, or --no-verify, which CLAUDE.md forbids).
lag-max 3
