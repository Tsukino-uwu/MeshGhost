# Pitfalls — the index of every lesson

**One line per entry, and every line ends in its OUTCOME.** `[CHECK: <what enforces it>]` means a
preflight section, hook, or test now makes the repeat impossible. `[RULE: <file>]` means the imperative
lives where the mistake is made — a checklist page or a `CLAUDE.md` that loads on contact. `[RECORD]`
means a story with no transferable rule yet; **a repeat of a RECORD lesson forces promotion**.
`dev-scripts/preflight.ps1` fails a body heading missing here, an untagged line, and a line that runs
past one line. The reading path is [../checklists/](../checklists/); this file is for finding the
record behind a lesson. How to file a new one: [../pitfalls.md](../pitfalls.md).
