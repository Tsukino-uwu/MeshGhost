# Open Items

THIS FILE IS OPEN ITEMS ONLY. Everything finished lives in `agent_docs/bug-fixes.md`.

## Purpose

Use this file for active bugs, investigations, and open issues that need tracking.

## Entry format

- `Date:`
- `Title:`
- `Status:` open / in progress / blocked
- `Description:` short summary of the problem
- `Steps to reproduce:` if known
- `Related docs:` links to `agent_docs/phases/*.md`, `agent_docs/verified.md`, or other notes

## Guidelines

- Do not move fixed issues here.
- Record only unresolved or currently investigated problems.
- Keep entries short and focused on symptoms and reproduction.
