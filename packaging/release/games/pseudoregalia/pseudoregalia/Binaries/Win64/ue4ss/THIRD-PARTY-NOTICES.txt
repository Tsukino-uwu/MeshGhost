MeshGhost -- third-party notices for the binaries in this folder
===============================================================

This folder ships UE4SS.dll and dwmapi.dll, built from this project's own pinned RE-UE4SS
submodule (see agent_docs/licensing.md and dev-scripts/stage-ue4ss-runtime.bat), plus
Mods/MeshGhostPseudo/dlls/main.dll, MeshGhost's own adapter.

RE-UE4SS's own MIT licence is the file named LICENSE beside this one. RE-UE4SS statically
links the third-party libraries listed below, so their notices travel with the binary here,
as MIT, BSD and zlib terms each require. MeshGhost's own main.dll links only UE4SS and the
Windows socket library, and adds no third-party code of its own.

Each notice below is reproduced verbatim from that project's own licence file in the source
tree the shipped binaries were built from. Nothing here is quoted from memory.

Generated by hand and kept by hand -- if a dependency is added or removed upstream, update
this file. Last reviewed: 2026-08-16.

patternsleuth
https://github.com/trumank/patternsleuth
===============================================================================

patternsleuth is statically linked into UE4SS.dll (as the patternsleuth_bind staticlib crate,
via Corrosion). It is the byte-pattern scanner UE4SS uses to locate Unreal Engine functions
and globals inside a shipping executable that has no symbols.

Upstream publishes NO licence file -- neither in the repository nor in the submodule checkout,
and GitHub reports no detected licence (checked 2026-08-16). The only grant it makes is the
declaration in its own Cargo.toml, reproduced here verbatim:

    license = "MIT OR Apache-2.0"

Authors, per the same Cargo.toml: trumank.

That declaration is the whole of the permission granted, so it is quoted rather than expanded
into standard MIT or Apache-2.0 text: writing out a copyright line upstream never wrote would
be inventing a fact, which this project does not do. Anyone needing the full text of either
licence should take it from the canonical source for the option they choose.
