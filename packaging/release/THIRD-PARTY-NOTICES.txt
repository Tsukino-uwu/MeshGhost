Third-party notices for meshghost.exe and meshghost-server.exe
==============================================================

MeshGhost itself is MIT licensed -- see LICENSE. This file exists because
both executables are statically linked Go binaries, so a few third-party Go
modules are compiled INTO them, and their licences require the notice to
travel with a binary. Nothing here is a separate file you need to install;
it is all already inside the .exe.

The list below is what actually linked, read from the built binary with
  go version -m meshghost.exe
rather than from go.mod -- go.mod also lists modules used only for tests and
tooling, which never reach these executables. Re-check this file whenever the
quic-go version moves, since its dependency set can change with it.
Last verified 2026-08-16 against quic-go v0.61.0.

Note golang.org/x/net appears in go.mod but does NOT link into these
binaries, so it is deliberately absent here.
